# Sistema de Triagem de PDVs

Projeto desenvolvido em Python para classificar
o impacto de problemas em PDVs de uma filial.

## Funcionalidades

- Cadastro de quantidade de PDVs da filial.
- Validação de quantidades informadas.
- Classificação do impacto em baixo, alto e nenhum impacto.

## Tecnologias

- Python
- Git e GitHub
